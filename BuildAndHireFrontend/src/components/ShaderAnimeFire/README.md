# Shader Anime Fire

Source: https://23rd.dev/docs/components/shader-anime-fire
Registry: https://23rd.dev/r/shader-anime-fire.json
Author: radiumcoders / 23rd.dev (https://github.com/radiumcoders/23rd.dev)
Retrieved: 27 October 2026.

The publicly distributed registry component has been adapted into a standalone
TypeScript engine and a React wrapper using CSS modules. No additional packages
are required. The shader, pointer interaction, reduced-motion behavior, hidden-tab
pausing, context recovery, and gradient fallback come from the upstream component.
Development logging uses Vite's environment flag. A speed of zero also stops the
animation loop for the page's pause control.

The upstream repository and registry did not include a license file when retrieved;
no license is asserted here. The upstream README invites copying components into
applications. This attribution preserves the source and author information.
